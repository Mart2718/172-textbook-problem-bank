Exercise \(\PageIndex{2}\)

Explain why each of the following equations does or does not define \(y\) as a function of \(x\).

  1. \(x^{5} = 8 y^{2}\)
  2. \(y^{5} = 8 x^{2}\)
Answer

a) This equation does not define \(y\) as a function of \(x\): when \(x = 2\), \(y^{2} = 4\), so \(y = -2\) or \(y = 2\). One input, two outputs.

b) This equation defines \(y\) as a function of \(x\): solving gives \(y = \sqrt[5]{8 x^{2}}\), and an odd root of a real number has exactly one real value, so each \(x\) gives exactly one \(y\).

Exercise \(\PageIndex{5}\)

Consider the two relations below.

  1. Does \(A = \{(3, 9), (-4, 2), (2, 4), (1, 9), (-1, 5)\}\) define a function? Explain.
  2. Does \(B = \{(2, 2), (9, -2), (-2, 6), (-3, 3), (-2, 9)\}\) define a function? Explain.
  3. Remove exactly one ordered pair from \(B\) so that it defines a function. Which pair(s) could you remove?
Answer

a) Yes. Each input appears exactly once. The inputs \(1\) and \(3\) share the output \(9\), and that is allowed: two inputs may have the same output.

b) No. The input \(-2\) is paired with two different outputs, \(6\) and \(9\).

c) Remove either \((-2, 6)\) or \((-2, 9)\). Either way, the input \(-2\) is left with one output.

Exercise \(\PageIndex{6}\)

Use the mapping below.

Mapping

  1. Does this mapping define a function? Explain.
  2. List the domain.
  3. List the range.
Answer

a) Yes. Each input has exactly one arrow. Two inputs sharing the output \(-2\) is allowed, and a target value with no incoming arrow (\(6\)) doesn't matter.

b) \(\{0, 1, 3, 5\}\)

c) \(\{-2, 0, 9\}\). The value \(6\) has no incoming arrow, so it is not an output and is not in the range.

Exercise \(\PageIndex{7}\)

Let \(f(x) = \sqrt{3 x - 6}\) and \(g(x) = \sqrt{9 - 2 x}\).

  1. Find the domain of \(f\). Write it in interval notation.
  2. Find the domain of \(g\). Write it in interval notation.
  3. Is \(f(1)\) a real number? Explain using part (a).
Answer

a) \([2, \infty)\)

b) \((-\infty, \frac{9}{2}]\)

c) No, \(f(1)\) is undefined: \(1\) is not in the domain \([2, \infty)\). The radicand is \(-3\), and the square root of a negative number is not real.

Exercise \(\PageIndex{8}\)

Let \(f(x) = \frac{\sqrt{x + 1}}{x - 1}\).

  1. Which inputs make the radicand negative?
  2. Which input makes the denominator zero?
  3. Write the domain of \(f\) in interval notation.
Answer

a) \(x \lt -1\)

b) \(x = 1\)

c) \([-1, 1) \cup (1, \infty)\)

Spot the Slip

Find the error, fix it, and explain your thinking.

Exercise \(\PageIndex{9}\)

A student was asked: Does \(\{(4, 7), (-1, 6), (6, 7), (0, 8)\}\) define a function? Explain.

A student's work:

"The output \(7\) shows up twice, at \((4, 7)\) and \((6, 7)\). So this relation is not a function."

  1. Find the slip in the student's reasoning and explain it in a sentence.
  2. Give the correct answer with a reason.
Answer

a) The student checked for repeated outputs. A function only forbids one input having two different outputs; two inputs sharing an output is allowed.

b) It is a function: the inputs \(4, -1, 6, 0\) each appear exactly once.

Looking Ahead to Calculus

An idea from this section that grows into calculus.

Exercise \(\PageIndex{10}\)

The graph of \(x^2 + y^2 = 25\) is a circle of radius \(5\) centered at the origin.

  1. Show that \(x^2 + y^2 = 25\) does not define \(y\) as a function of \(x\) by finding one input with two outputs.
  2. Solve for \(y\). You should get two functions. Which one gives the top half of the circle?
  3. What is the domain of the top-half function?
Answer

a) When \(x = 4\), \(y^2 = 9\), so \(y = -3\) or \(y = 3\). (Other inputs work too.)

b) Top half: \(y = \sqrt{25 - x^{2}}\). (The other function, \(y = -\sqrt{25 - x^{2}}\), gives the bottom half.)

c) \([-5, 5]\)
