Exercise \(\PageIndex{1}\)

Let \(k(x) = \begin{cases} \sqrt{x^{2} + 1} & -5 < x < 2 \\ \frac{4 x - 2}{x^{2} + 4} & 2 \le x < 5 \end{cases}\).

  1. Find \(k(3)\).
  2. Find \(k(-3)\).
  3. Find \(k(2)\).
Answer

a) \(k(3) = \frac{10}{13}\)

b) \(k(-3) = \sqrt{10}\)

c) \(k(2) = \frac{3}{4}\)

Exercise \(\PageIndex{5}\)

Let \(p(x) = x^{2} - 7\).

  1. Find \(p(4)\).
  2. Find and simplify \(p(a+1)\).
  3. Find every input \(x\) for which \(p(x) = -3\).
Answer

a) \(p(4) = 9\)

b) \(p(a+1) = a^{2} + 2 a - 6\)

c) \(x = -2\) or \(x = 2\)

Exercise \(\PageIndex{6}\)

Let \(g(x) = \begin{cases} \sqrt{x + 6} & -6 \le x < 0 \\ x^{2} - x - 1 & 0 \le x \le 4 \end{cases}\).

  1. Find \(g(-2)\), or explain why it is undefined.
  2. Find \(g(0)\), or explain why it is undefined.
  3. Find \(g(6)\), or explain why it is undefined.
Answer

a) \(g(-2) = 2\)

b) \(g(0) = -1\) (the boundary value \(0\) belongs to the second piece)

c) \(g(6)\) is undefined: \(6\) is not in the domain \([-6, 4]\), so neither piece applies.

Exercise \(\PageIndex{7}\)

Let \(p(x) = \frac{4 x - 1}{x + 1}\).

  1. Find \(p(0)\).
  2. Explain why \(p(-1)\) is undefined.
  3. Solve \(p(x) = 3\).
Answer

a) \(p(0) = -1\)

b) Substituting \(-1\) makes the denominator \(x + 1\) equal to \(0\), and division by zero is undefined.

c) \(x = 4\)

Spot the Slip

Find the error, fix it, and explain your thinking.

Exercise \(\PageIndex{9}\)

A student was asked: Let \(f(x) = x^{2} - 3\). Find every input \(x\) for which \(f(x) = 6\).

A student's work:

\(x^{2} - 3 = 6\)
\(x^2 = 9\)
\(x = 3\)
"So the only input is \(x = 3\)."

  1. Find the slip in the student's work and explain it in a sentence.
  2. Give the correct answer and check it.
Answer

a) Going from \(x^2 = 9\) to \(x = 3\) misses a solution: both \(3\) and \(-3\) square to \(9\).

b) \(x = -3\) or \(x = 3\). Check: \(f(-3) = (-3)^2 - 3 = 6\) and \(f(3) = 3^2 - 3 = 6\).

Looking Ahead to Calculus

An idea from this section that grows into calculus.

Exercise \(\PageIndex{10}\)

Let \(g(x) = x^{2} + 2 x\).

  1. Find and simplify \(\frac{g(3+h) - g(3)}{h}\) for \(h \ne 0\).
  2. Evaluate your answer for \(h = 0.1\), \(h = 0.01\), and \(h = 0.001\). What number do the values approach as \(h\) gets closer to \(0\)?
  3. The expression in part (a) is the slope of the secant line through two points on the graph of \(g\). Which two points?
Answer

a) \(h + 8\)

b) \(h = 0.1\): \(8.1\), \(h = 0.01\): \(8.01\), \(h = 0.001\): \(8.001\). The values approach \(8\).

c) \((3, 15)\) and \((3+h, h^{2} + 8 h + 15)\), that is, \((3, g(3))\) and \((3+h, g(3+h))\). As \(h\) shrinks, the second point slides toward the first, and the secant slopes approach the slope of the tangent line at \(3\), which is \(8\).
