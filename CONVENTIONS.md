# Answer & Vocabulary Conventions

The house style for every problem and answer in this bank. The generators follow it, and auditors check against it.

**Sources:** TBIL CheckIt generators (S1), the FN2/FN3 FAQ and guided learning (S2), Quizzes 1–3 and Midterm 1 (S3).
Rows marked **⚑ confirm** are my best reading and need Dr. Romero's OK.

**Status:** DRAFT, awaiting approval.

## Numbers

| Situation | Convention | Source |
|---|---|---|
| Evaluating formulas | **Exact**: reduced fractions, simplified radicals (\(2\sqrt{7}\), not \(\sqrt{28}\)), no decimals unless the problem gives decimals | S1, S2 |
| Values read from a graph | Integers or **decimals** (\(x = 1.5\)), matching CheckIt; never fractions | S1 |
| Applied/context answers (PR2, LF5) | Units on every answer; round as the problem says, otherwise to 2 decimal places ⚑ confirm | S1 (PR2 "nearest"), S3 |
| Negative numbers squared | Parentheses when substituting: \((-3)^2\) | S2 |

## Lists of solutions

- Several solutions: \(x = -3, \; x = 3, \; x = 6\) in increasing order (CheckIt writes "x=−3, x=3, x=6"). (S1, S2)
- No solution: "There is no \(x\) with \(f(x) = k\)," with a reason ⚑ confirm wording.
- Two solutions from squaring: "\(x = -4\) or \(x = 4\)." (S3)

## Notation

| Item | Convention | Source |
|---|---|---|
| Domain, range, increasing/decreasing | **Interval notation**; unions with \(\cup\) | S1, S2 |
| Increasing/decreasing intervals | **Open** intervals, even at a filled dot | S2 |
| Points | \((x, y)\) with parentheses, never brackets | S3 (fix logged in blueprint) |
| Piecewise conditions | \(-5 < x \le 2\) style; exactly one piece includes the boundary value | S1, S2 |
| Function names | \(f, g, k, p, q\); **\(h\) is never a function name**: it's reserved for the increment in \(f(x+h)\) | Build rule + FN2 audit |

## Vocabulary

| Use | Not | Source |
|---|---|---|
| **boundary value** (piecewise) | break point, cut | S2 |
| input / output (with x-value / y-value as a gloss) | argument, image | S2 |
| closed (filled) dot / open (hollow) dot | solid/empty circle | S2 |
| local max/min; global max/min | relative/absolute ⚑ confirm | S2 |
| **secant line** (through two points) vs **tangent line** (the limit) | "a line" for either | FN2 audit |
| "undefined: \(x\) is not in the domain" | "DNE", "error" | S2, S3 |
| "undefined: division by zero" (rational) | "infinity" | S3 |

## Course rules that answers must respect

- An **endpoint is never a local max or min**; a filled endpoint **can** be the global max or min. An open dot is never reached, so it can't be either. (S2)
- Graph sketches meeting criteria: "Answers will vary," with one example graph. (S1)
- Angle graphs: sides are rays with arrowheads; segments ending in a dot only on a unit circle with a marked point. (course rule)
- Spot the Slip has exactly **one** deliberate error. (S2)

## Answer-block style

- Lettered answers `a) … b) …`, matching the template.
- Short answers only; full solutions are reserved (see SCHEMA.md).
- "Explain" parts get a one- or two-sentence model answer, not a full essay.
