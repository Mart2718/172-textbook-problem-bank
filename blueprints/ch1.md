## 3. Issues found in the source assessments

Logged here so the bank doesn't inherit them, and so they can be fixed in future versions.

| # | Where | Issue | Suggested fix |
|---|---|---|---|
| 1 | Quiz 1, 1.2.2a | The criteria contradict each other: a local min at x = −3 inside a decreasing interval (−10, 3) | Decreasing on (−10, −3) ∪ (5, 10); increasing on (−3, 5) |
| 2 | Quiz 1, 1.2.2a | "[0, −2]" for a point; stray "]" | (0, −2) |
| 3 | Quiz 1, 1.1.1b | "function of not" | "function or not" |
| 4 | Quiz 2, LF5 | Leftover line "LibreTexts §1.4 · CheckIt outcome LF5" | Delete |
| 5 | Midterm 2B | √(x−1) on −4 < x < 1 is not real anywhere, so f(−3) is undefined | e.g., √(x+5) or √(1−x) |
| 6 | Midterm 6B | g(x) = (x−1)² is not one-to-one | Add "for x ≥ 1" |
| 7 | Quiz 3, 1.8b | The graph's alt text is a garbled auto-generated caption | "Graph of f: the lower half of a circle centered at the origin with radius 2, from (−2, 0) down to (0, −2) and back up to (2, 0)." |
| 8 | Quiz 3, 1.6b | The graph has no alt text | List each function's vertices: p: (−4,3), (−2,−1), (1,2), (3,0), (4,3); q: (−4,−2), (−2,2), (1,2), (3,0), (4,1) |

Checked and correct: Quiz 3 1.6b. (p∘q)(0) = 1, q(p(0)) = 2, (q∘p)(−3) = 2, and q(p(x)) = 0 at x = −4 and x = 4.
